# TEL-03: Коннектор Telegram Bot API

## Описание
Необходимо разработать Go-клиент для Telegram Bot API в качестве нового коннектора в монорепозитории `nativebpm/connectors`.
Движок бизнес-процессов NativeBPM должен иметь возможность отправлять уведомления, документы, фотографии, обрабатывать нажатия интерактивных кнопок (Callback Queries) и получать входящие обновления.

## Требования
1. **Интеграция с httpstream**: Использовать `httpstream.Client` в качестве базового HTTP-клиента для реализации высокоэффективного стриминга файлов (документов, изображений) без полной буферизации в оперативной памяти.
2. **Основные методы**:
   - `SendMessage` — отправка текстовых сообщений с форматированием (HTML/Markdown) и поддержкой клавиатур.
   - `SendDocument` — отправка файлов через `io.Reader`.
   - `SendPhoto` — отправка изображений через `io.Reader`.
   - `AnswerCallbackQuery` — ответ на нажатия инлайн-кнопок.
   - `SetWebhook` — регистрация URL вебхука.
   - `GetUpdates` — получение обновлений методом длинных опросов (long-polling) для локальной разработки.
3. **Модели данных**: Описать основные структуры Telegram (Update, Message, Chat, User, CallbackQuery, InlineKeyboardMarkup, ReplyKeyboardMarkup и др.).
4. **Тесты**: Покрыть клиент юнит-тестами с использованием `httptest.Server` для верификации корректности сериализации параметров и потоковой отправки файлов.
