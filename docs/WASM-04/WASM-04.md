# WASM-04: Durable Execution Engine на базе WebAssembly (WASM)

## Описание задачи
Разработка MVP отказоустойчивого движка для выполнения бизнес-логики (Durable Execution Engine) на базе WebAssembly (WASM). Движок должен обеспечивать выполнение кастомного кода в изолированной песочнице с возможностью сохранения состояния памяти (snapshotting) и восстановления при сбоях, а также использовать $O(1)$ потребление памяти при передаче данных.

## Требования
1. **WASM Worker (tinygo)**:
   - Шаги: инициализация -> получение потока данных -> трансформация -> завершение.
   - Синхронное выполнение без горутин.
   - Вызов хост-функций для сети.
2. **Go Host (wasmtime-go)**:
   - Инициализация `wasmtime.Store` и модуля.
   - Хост-функция `stream_data` с паттерном `Stream-first HTTP` через `io.Pipe` ($O(1)$ RAM).
3. **Механизм снапшотов (Durable Execution)**:
   - Сохранение линейной памяти на диск при вызове `checkpoint` или шаге выполнения.
   - Восстановление нового инстанса из снапшота памяти и продолжение работы.
4. **Сборка и развертывание**:
   - `Makefile` для сборки `tinygo` и хоста.
   - `Dockerfile` на базе `scratch` для хоста.
