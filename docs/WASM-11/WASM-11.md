# WASM-11: Продакшн-ready улучшения для Durable WASM

## Описание задачи
Реализация ключевых архитектурных улучшений для обеспечения стабильности и надежности Durable WASM движка при долгосрочном сне бэкенда (6+ месяцев), предотвращения Split-Brain (OCC), детерминизма времени и защиты от несовместимости версий WASM-модулей.

## Компоненты для доработки
1. **WASM Module Versioning**: Контроль хэша (SHA256) WASM модуля при загрузке снапшота.
2. **Optimistic Concurrency Control (OCC)**: Предотвращение Split-Brain с помощью версионирования эпохи инстанса при сохранении чекпоинтов.
3. **Oplog Truncation**: Периодическое создание полных снапшотов памяти и очистка старого Oplog/Deltas.
4. **Deterministic Time**: Хост-функция `host_get_time` с логированием в Oplog для устранения дрейфа времени при Replay.
5. **NaN Canonicalization**: Настройка детерминизма float вычислений в конфигурации Wasmtime.
