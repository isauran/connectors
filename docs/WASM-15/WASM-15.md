# WASM-15: Разработка Go SDK для Durable WASM

## Описание задачи
Создать Go SDK непосредственно внутри корневого пакета `durable-wasm` (экспортируемого из пакета `durable`), который скрывает от разработчика низкоуровневые детали взаимодействия с хостом (такие как `unsafe.Pointer`, ручной вызов `//go:wasmimport`, работа с сырыми потоками `stream_data` и ручной менеджмент состояний через `switch step` конечного автомата).

С использованием SDK разработчик должен писать чистый, линейный код на Go с использованием Fluent API, определяя бизнес-логику в виде последовательности шагов (Workflow) и выполняя детерминированные вызовы хоста.

## Требования к SDK
1. **Интеграция в корневой пакет**: Все функции SDK должны быть доступны прямо из пакета `durable`.
2. **Типобезопасные обертки**:
   - `durable.GetTime() time.Time` (детерминированное время).
   - `durable.CallAPI(apiName string, req []byte) ([]byte, error)` (детерминированные вызовы внешних систем через Oplog).
   - `durable.Reader` и `durable.Writer` (реализующие стандартные `io.Reader` и `io.WriteCloser` поверх `stream_data`).
3. **Fluent API для воркфлоу**:
   - Структура `durable.Workflow` и методы `.Step(...)` и `.Run()` для связывания и запуска этапов бизнес-логики.
   - Автоматическое управление шагами и вызов `checkpoint()` после каждого завершенного шага.
4. **Fluent API для внешних вызовов**:
   - Структура `durable.APICall` с методами `durable.Call(...)`, `.WithPayload(...)` и `.Send()`.
5. **Совместимость сборки хоста**:
   - Использование build tags (`//go:build wasm` для SDK и `//go:build !wasm` для файлов хоста/заглушек) для предотвращения ошибок компиляции Wasmtime C API при сборке хост-тестов.
6. **Обновление примера**:
   - Перевести пример `examples/s3-store` на использование нового SDK для демонстрации простоты кода.
