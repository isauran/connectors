# WASM-06: Реструктуризация модуля durable-wasm

## Описание задачи
Необходимо очистить корень Go-модуля `durable-wasm`, чтобы подготовить его к публикации в качестве публичной библиотеки. Все демонстрационные файлы песочницы (координатор хоста, worker, docker-окружение) должны быть перенесены в каталог `examples/simple/`. Код ядра движка должен находиться непосредственно в корне модуля `durable-wasm` под пакетом `durable`.
