# WASM-10: Обновление golangci-lint до версии v2

## Описание задачи
Текущая конфигурация линтера использует устаревшую версию. Необходимо обновить `golangci-lint` до актуальной мажорной версии v2 (например, v2.12.2), адаптировать файл конфигурации `.golangci.yml`, настроить Makefile и запустить линтер для проверки кодовой базы.
