# WASM-16: Рефакторинг ядра Durable WASM и ребрендинг в Wasman

## Описание задачи
Текущий модуль `durable-wasm` содержит монолитный файл `engine.go` (~750 строк), объединяющий в себе структуры типов, логику выполнения (Execution), логику стриминга сессий (Session) и инициализацию движка (Engine). Требуется декомпозировать этот файл для улучшения читаемости и поддержки.

Дополнительно, необходимо выполнить ребрендинг (переименование) модуля `durable-wasm` и пакета `durable` в новое звучное и лаконичное имя — **`wasman`** (Wasm-Man).

## Цели
1. Разбить `engine.go` на файлы `types.go`, `execution.go`, `session.go` и `engine.go`.
2. Переименовать директорию `durable-wasm` в `wasman` через `git mv`.
3. Обновить имя Go-модуля на `github.com/nativebpm/connectors/wasman` в `go.mod`.
4. Обновить имя пакета на `wasman` во всех Go-файлах модуля.
5. Обновить пути импорта модуля в примерах (`examples/`) и корневом `go.work`.
6. Обновить Makefile, конфигурационные файлы и документацию.
7. Проверить сборку и успешное прохождение тестов.
