# WASM-19: Полная поддержка спецификации BPMN 2.0 и интеграционное тестирование

## Описание задачи
Требуется расширить Go-модуль `bpmn` до полной поддержки элементов спецификации BPMN 2.0, используемых в реальных бизнес-процессах Camunda. Это позволит запускать любые стандартные схемы (включая обработку событий, ошибок, вложенных подпроцессов и таблиц решений DMN) на нашем легковесном движке.

## Цели
1. **Поддержка BusinessRuleTask**:
   - Парсинг `<businessRuleTask>` с атрибутами `decisionRef`, `mapDecisionResult` и `resultVariable`.
   - Интеграция с существующим DMN движком (`dmn.go`) для автоматического вычисления правил и сохранения результатов в переменные процесса.
2. **Поддержка Граничных Событий (Boundary Events)**:
   - Парсинг `<boundaryEvent>` с вложенными определениями событий (`timerEventDefinition`, `messageEventDefinition`, `errorEventDefinition`).
   - Реализация прерывания родительской задачи при возникновении события.
3. **Поддержка Вложенных Подпроцессов (Subprocesses)**:
   - Парсинг `<subProcess>` и рекурсивная индексация его внутренних элементов.
   - Управление жизненным циклом подпроцесса (вход через внутренмый `StartEvent`, выход через `EndEvent` подпроцесса в родительский поток).
4. **Поддержка Подпроцессов Событий (Event Subprocesses)**:
   - Парсинг `<subProcess triggeredByEvent="true">`.
   - Запуск подпроцесса события по входящему сообщению с прерыванием всего текущего выполнения процесса (если `isInterrupting="true"`).
5. **Интеграционное тестирование**:
   - Написание тестов для всех новых конструкций.
   - Сквозные тесты на реальных BPMN схемах (`events.bpmn`, `subprocesses.bpmn`, `dmn_business_rule.bpmn`).
