# WASM-17: Создание модуля bpmn для имплементации BPMN 2.0 и DMN движка

## Описание задачи
Требуется создать отдельный Go-модуль `bpmn`, который будет реализовывать движок выполнения процессов стандарта BPMN 2.0 и таблиц решений DMN (Decision Model and Notation).
Этот движок должен использовать разработанный модуль `wasman` в качестве низкоуровневого SDK для выполнения изолированных шагов (воркеров) в WASM с сохранением точек восстановления (checkpoints).

## Цели
1. Создать новую директорию `bpmn` в корне монорепозитория.
2. Инициализировать Go-модуль `github.com/nativebpm/connectors/bpmn` и подключить его к `go.work`.
3. Подключить модуль `wasman` как локальную зависимость.
4. Разработать базовую структуру движка, включая:
   - Парсинг BPMN 2.0 схем (узлы, переходы, шлюзы).
   - Интерфейс для интеграции DMN таблиц.
   - Механизм сохранения состояния выполнения (очередь шагов, текущие активные токены) с использованием checkpoints в `wasman`.
5. Покрыть базовую реализацию тестами.
