# WASM-20: Реализация расширенной спецификации BPMN 2.0

## Описание задачи
Требуется расширить возможности Go-модуля `bpmn` до поддержки расширенных элементов спецификации BPMN 2.0: инклюзивных шлюзов (OR), не-прерывающих граничных событий, сигнальных событий, механизма компенсации шагов и мульти-инстанс задач. Это сделает движок функционально законченным и готовым к любым сложным корпоративным сценариям.

## Цели
1. **Инклюзивные шлюзы (Inclusive Gateway — OR)**:
   - Поддержка `<inclusiveGateway>` для разветвления (активация всех веток с истинными условиями) и слияния (ожидание всех потенциально достижимых активных токенов через анализ путей графа).
2. **Не-прерывающие события**:
   - Поддержка граничных событий с `cancelActivity="false"`. При их срабатывании родительская задача продолжает выполняться, а параллельно запускается новая ветка.
3. **Сигнальные события**:
   - Поддержка широковещательных сигналов (`signalEventDefinition`) для одновременного запуска нескольких обработчиков.
4. **Компенсация (Saga Pattern)**:
   - Внедрение истории выполненных шагов в `ProcessInstance`.
   - Поддержка граничных компенсационных событий и ассоциаций с компенсирующими задачами.
5. **Мульти-инстансы (Multi-Instance Tasks)**:
   - Поддержка запуска циклов задач (последовательных и параллельных) для обработки коллекций данных.
6. **Тестирование**:
   - Написание юнит-тестов для каждого нового элемента спецификации.
