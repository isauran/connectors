# WASM-05: Интеграция httpstream в durable-wasm

## Описание задачи
Необходимо интегрировать внутренний пакет `httpstream` в ядро `durable-wasm` для отправки HTTP-запросов (загрузка и выгрузка медиа/данных). Это позволит отказаться от прямых низкоуровневых вызовов `net/http` и использовать унифицированный Fluent API пакета `httpstream`, сохраняя при этом потоковую передачу данных без OOM.
