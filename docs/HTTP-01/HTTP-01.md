# HTTP-01: Исправление зависания ConcurrencyMiddleware при отмене контекста

В текущей реализации `ConcurrencyMiddleware` в пакете `httpstream` операция захвата слота в семафоре (`c.sem <- struct{}{}`) блокируется синхронно и игнорирует отмену контекста запроса. Это может приводить к утечкам горутин и задержкам при высокой нагрузке, когда отменённые клиенты продолжают стоять в очереди.

## Требования:
1. Изменить логику `RoundTrip` в `limit.go`, добавив выбор через `select` между отправкой в канал и отслеживанием `req.Context().Done()`.
2. Создать файл тестов `limit_test.go` для проверки:
   - Ограничения параллельных запросов.
   - Быстрой отмены заблокированного запроса при отмене его контекста.
