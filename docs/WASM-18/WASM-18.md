# WASM-18: Поддержка асинхронных шагов ожидания (Wait State) в BPMN-движке

## Описание задачи
Требуется добавить в разработанный Go-модуль `bpmn` полноценную и надежную поддержку асинхронных шагов ожидания (Wait State), на которых выполнение процесса приостанавливается до наступления внешнего события.
Это необходимо для реализации следующих элементов стандарта BPMN 2.0:
1. `UserTask` — задача, требующая участия пользователя (например, ручное одобрение).
2. `ReceiveTask` — задача ожидания входящего сообщения от внешней системы.
3. `IntermediateCatchEvent` — промежуточное событие ожидания (например, получение сообщения).

## Цели
1. Поддержка парсинга элементов `<userTask>`, `<receiveTask>` и `<intermediateCatchEvent>` в модуле `bpmn.go`.
2. Внедрение списка ожидания `WaitingTokens []string` в структуру `ProcessInstance` для отслеживания припаркованных токенов.
3. Доработка логики метода `Step()` в `engine.go` для корректной приостановки исполнения на шагах ожидания.
4. Реализация API-метода корреляции `CompleteTask(instance *ProcessInstance, nodeID string, variables map[string]interface{}) error` для возобновления процесса и передачи новых переменных.
5. Написание модульных тестов, проверяющих засыпание и пробуждение процесса на шагах ожидания.
