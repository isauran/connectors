# TEMP-02: Пример демонстрации Activity Heartbeats в Temporal

## Описание задачи
Необходимо разработать демонстрационный пример, иллюстрирующий концепцию **Activity Heartbeats** в Temporal.io с использованием Go SDK. 

Пример должен наглядно показывать:
1. Как активировать и настроить Heartbeat Timeout в `ActivityOptions`.
2. Как периодически отправлять Heartbeat-сообщения из долгоиграющей Activity (`activity.RecordHeartbeat`).
3. Как отслеживать отмену Activity через контекст (`ctx.Done()`).
4. Как сохранять текущий прогресс (состояние) в Heartbeat Payload.
5. Как при перезапуске (retry) упавшей Activity получить сохраненное состояние через `activity.GetHeartbeatDetails` и продолжить выполнение с места прерывания.

## Сценарий демонстрации
1. Воркер запускает долгоиграющую задачу, состоящую из 10 шагов (имитация обработки данных). Каждый шаг занимает 1 секунду.
2. В `ActivityOptions` задается короткий `HeartbeatTimeout = 2 * time.Second` и `RetryPolicy` с ограничением попыток.
3. На первом запуске (Attempt 1) после шага 4 Activity намеренно прекращает отправку Heartbeats (засыпает на 4 секунды).
4. Temporal Server фиксирует превышение таймаута Heartbeat (`HeartbeatTimeout`) и принудительно перезапускает Activity (Attempt 2).
5. На втором запуске Activity считывает детали последнего успешного Heartbeat, видит, что шаг 4 был успешно завершен, и продолжает выполнение с шага 5 до конца.
