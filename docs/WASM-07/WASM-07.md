# WASM-07: Хранение снапшотов в SQLite и репликация в S3 через Litestream

## Описание задачи
Необходимо перевести хранение снимков памяти (снапшотов WASM) из бинарных файлов на диске в базу данных SQLite, чтобы реализовать надежное транзакционное хранилище. Для обеспечения отказоустойчивости и возможности распределенного запуска необходимо настроить автоматическую репликацию SQLite-базы на внешнее S3-совместимое хранилище в реальном времени с помощью Litestream, а также предусмотреть автоматическое восстановление базы из S3 перед стартом хост-приложения.
