# WASM-21: Агрегированное S3-индексирование для визуализации процессов в Cockpit

## Описание задачи
Для мониторинга выполняющихся процессов (BPMN/DMN) в кастомной Cockpit-панели необходим список всех активных инстансов с их текущим статусом. Так как состояние процессов (`ProcessInstance` и снапшоты WASM) сохраняется в S3-совместимом объектном хранилище, прямой поиск/листинг сотен тысяч папок инстансов неэффективен.

В рамках этой задачи необходимо реализовать паттерн **Index File Pattern**:
1. Вести в корне S3-бакета единый файл-индекс активных процессов (например, `instances/active_index.json`).
2. При создании, переходе по шагам (`Step`) или завершении процесса движок должен обновлять запись этого инстанса в агрегированном индексе.
3. Обеспечить защиту от конкурентной перезаписи индексного файла несколькими инстансами движка с помощью механизма OCC (Optimistic Concurrency Control / ETag / If-Match).
