# WASM-12: Повышение стабильности и стресс-тестирование Durable WASM движка

## Описание задачи
Реализовать оптимизации стабильности в пакете `durable-wasm` для защиты от утечек файловых дескрипторов, сетевых горутин и C-памяти Wasmtime. Покрыть движок новыми классами стресс- и отказоустойчивых тестов.

## Требования
1. **Переиспользуемый HTTP-клиент**:
   - Вынести `http.Client` из структуры `Engine` или сделать его конфигурируемым, чтобы избежать Socket Exhaustion при создании множества движков.
2. **Context-aware Execution**:
   - Изменить сигнатуру `Execute` на `Execute(ctx context.Context, instanceID string, entrypoint string, serverAddr string, shouldCrash bool)`.
   - Связать жизненный цикл асинхронного сетевого стриминга в `handleUpload` с контекстом сессии.
3. **Очистка C-ресурсов Wasmtime**:
   - Вызывать явный метод `Store.Close()` (или `Close` связанных структур) для предотвращения раздувания C-кучи (cgo).
4. **Тест-кейсы**:
   - Добавить тесты отмены контекста.
   - Добавить тесты инъекции ошибок в `SnapshotStore`.
   - Добавить стресс-тест на циклическое выполнение 500 инстансов WASM.
