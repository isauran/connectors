# CAM-03: Camunda CDC Outbox Пример без REST-запросов

Необходимо реализовать пример, демонстрирующий паттерн Outbox для Camunda 7. Новые внешние задачи должны перехватываться триггером на уровне базы данных, объединяться со своими переменными и бизнес-ключом, после чего записываться в таблицу `camunda_outbox`. 

Воркер должен получать полную информацию о задаче (включая переменные и бизнес-ключ) непосредственно из Sequin CDC-потока, исключая необходимость в REST-запросах для блокировки (`Lock`) и получения переменных (`GetVariables`).
